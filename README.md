eDocker is a professional-grade, open-source desktop GUI for Docker, built for speed and elegance. By combining the safety and performance of **Rust** with the flexibility of **Vue 3**, eDocker provides a seamless management experience without the heavy resource footprint of traditional Electron apps.

## ✨ Highlights

- **⚡ Blazing Fast:** Boots in milliseconds. Uses less than 100MB of RAM.
- **🎨 Modern UI:** Sleek dark mode, responsive layouts, and buttery-smooth transitions.
- **🛠️ Power Tools:** Built-in interactive terminal, smart log streaming, and resource inspection.
- **🛡️ Secure & Private:** Runs entirely locally. Your data and credentials never leave your machine.
- **🐧 Multi-platform:** Native support for macOS (Intel/M-series), Windows, and Linux.

## 🚀 Quick Start

1. **Download** the latest version from our [Releases Page](https://github.com/phanvantam/eDocker/releases).
2. **Install** and launch the application.
3. Keep your Docker Desktop or Engine running, and eDocker will automatically connect!

## 🛠️ Built With

- [Tauri](https://tauri.app/) - Frontend-independent application framework.
- [Vue 3](https://vuejs.org/) - The Progressive JavaScript Framework.
- [Bollard](https://github.com/fussybeaver/bollard) - Async Docker API client for Rust.
- [Tailwind CSS](https://tailwindcss.com/) - Utility-first CSS framework.
